## 为什么做这个项目

科学教育的最终目标是提升人的**科学素养**，而科学素养由**科学知识**与**科学思维**共同组成，两者同等重要。

教材中的科学知识高度系统化、模块化，而科学思维的教学长期不成体系。本项目尝试把科学思维整理成一个个明确的知识点，分出层次结构、确定练习与考核方法，并用交互式网页降低学习门槛。

## 功能特性

| 模块 | 说明 |
| --- | --- |
| **总览** | 四大模块 × 十五个知识点卡片，学习进度自动记录 |
| **结构化笔记** | 一/二/三级标题清晰排版；关键术语、易错警示、方法口诀三色高亮，悬停可看释义；侧边目录滚动跟随 |
| **互动实验室** | 7 个可操作的演示与测验，把抽象概念变成可动手的实验 |
| **Anki 复习卡片** | 37 张卡片随机抽取、3D 翻转、自评评级；“不会”的卡片加权高频出现；模块掌握度雷达图 |

其他特性：

- 学习进度与卡片掌握情况通过 `localStorage` 本地持久化，不上传任何数据
- 响应式设计，桌面 / 平板 / 手机均可使用
- 键盘快捷键：复习界面 `空格` 翻转卡片、`→` 下一张

## 使用方法

无需安装、无需构建：

1. 直接下载 [`scientific-thinking-15.html`](scientific-thinking-15.html)
2. 用任意现代浏览器（Chrome / Edge / Firefox / Safari）打开即可
3. 建议联网首次打开（字体与 ECharts 图表库通过 CDN 加载）

也可以克隆本仓库后本地打开：

```bash
git clone https://github.com/tom61-bl/scientific-thinking-15.git
cd scientific-thinking-15
# 直接双击 scientific-thinking-15.html
```

## 互动实验室一览（15 条全覆盖）

| # | 知识点 | 互动形式 |
| --- | --- | --- |
| 01 | 事实和观点 | 拖拽分类 10 个易混句子 |
| 02 | 科学和技术 | 把成就拖入「科学发现 / 技术发明」 |
| 03 | 信源 | 逐层点击追溯，找到一手信源 |
| 04 | 信源可靠度 | 点击七层金字塔查看定义与案例 |
| 05 | 统计眼光 | 选择性记忆模拟器，看错觉如何产生 |
| 06 | 先后与因果 | 判断测验：先后还是因果？ |
| 07 | 因果与相关 | 三组散点图，找出第三变量 |
| 08 | 逻辑规则 | 谬误捕手测验，识别 8 种逻辑谬误 |
| 09 | 类比与推演 | 判断论证是类比还是逻辑推演 |
| 10 | 举证责任 | 谁主张谁举证判断测验 |
| 11 | 科学共同体 | 同行评审四环节流程拆解 |
| 12 | 哲学思辨与科学思考 | 科学思考四步走选择题 |
| 13 | 经验与规律 | 判断说法是经验还是客观规律 |
| 14 | 双盲实验 | 金标准四环节，少一步会怎样 |
| 15 | 可证伪性 | 命题判官：判断是否属于科学 |

## 技术栈

- 原生 **HTML / CSS / JavaScript**，无框架、无构建步骤
- [ECharts](https://echarts.apache.org/)（CDN 引入）—— 散点图、柱状图、漏斗图、雷达图
- 思源宋体 / 思源黑体
- 全部状态保存在浏览器 `localStorage`
